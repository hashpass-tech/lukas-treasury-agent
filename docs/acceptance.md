The second-currency extension uses generic token metadata/decimals and the same vault/payment math. One accepted settlement-token price is configured per treasury runtime. A second currency requires another verified token/feed and its separately configured treasury/runtime; a combined multi-currency dashboard is a P1 extension. The application uses raw EIP-1193 wallet requests with pinned viem rather than adding unused wagmi dependencies. Optional parsing requires no LLM key and cannot authorize execution.

## Executed verification

On 2026-10-08, Node 24.19.0 and pnpm 9.15.9:

- Unit/property/configuration/identity suite: 26 tests, including 300 random arithmetic cases and a clearly labeled local registry behind an ERC-1967 proxy.
- Native Foundry: 10 tests, including 256 fuzz runs, exact ceiling, malicious sender-fee and reentrant tokens, rollback, replay, UTC reset, ERC-1271, native normalization and signed-mirror freshness/replay.
- Integration: 17 tests on isolated actual EVM contracts; durable preparation before signing, signed-journal recovery, accepted-but-unrecorded submissions, reorgs, delayed mining, fee replacement, caps, permissions, authentication and signer nonce confinement.
- Browser: 3 tests, covering newly signed settlement, visibly unpaid cap violation, pause/resume/withdrawal/funding.
- HTTPS Sepolia-path emulator: 1 full deployment/funding/scheduled-payment/restart test. This is a local emulator with chain ID 11142220, not actual Celo Sepolia activity.
- Production build, strict TypeScript, Prettier lint and frozen dependency installation are required at final handoff; their current recorded results follow the final verification run.

No tests substitute for independent contract review. Docker, live Celo fork, actual Sepolia/mainnet, canonical network registration and independent merchant checks were not run. Labeled screenshots/video are simulation artifacts. Actual configured deployment addresses and receipts are generated under private `.local/`; those from local runs identify only that local EVM instance.
