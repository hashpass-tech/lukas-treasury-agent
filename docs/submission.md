# Hackathon submission draft

**LUKAS Treasury — owner-authorized local-currency settlement for Latin American supplier obligations.** Repository: https://github.com/hashpass-tech/lukas-treasury-agent. Track intent: Stable Agents: LatAm | Ripio x Celo, Agents on Open Rails.

A merchant schedules a supplier obligation in the LUKAS regional reference index, selects its recipient and bounds settlement amount/time. The agent evaluates live policy and fresh prices, pays autonomously when due, and reconciles an actual vault receipt. Owner custody, allowlists, caps, cancellation/pause and withdrawal remain independent of the agent. The runtime applies JACK principles and is independently implemented pending source reuse permission.

Permanent entry wallet: `0x114d72D97Aa9C413A1ba3f0Cd37F439D668EA1aD`. Issued transaction tag: `celo_41fbb6a88a82`. Only chain 42220 counts. Canonical agent ID, hosted metadata URL, actual official wFIAT deployment/payment receipts and credited event activity are **pending**, not invented. The repository includes canonical registration tooling and complete remote deploy/payment adapters.

The [demo](demo-script.md) and committed screenshots/video show explicitly labeled local simulation with actual local EVM transfers. The HTTPS Sepolia-path test uses a local emulator, not actual testnet. Tests exercise exact arithmetic, contract permissions, malicious tokens, encrypted journals, crashes, uncertain submission, replacement, delayed mining, reorgs, signer confinement, identity tooling and browser review.
