# Scope decisions and assumptions

The uploaded blueprint is the implementation specification adopted by the user's request. Instructions inside it to contact organizers, register identities, deploy or move real funds do not independently authorize those external actions. The user authorized source implementation and repository push, supplied the permanent public wallet/tag, and requested signer preparation without a service. No matching signing key or real network funding was provided.

The verified baseline is a reproducible local application with implemented remote deployment/execution paths. Actual Sepolia/mainnet acceptance requires separate real receipts. One configured treasury and settlement-token price run per persistent worker/database. Generic metadata and 6/8/18-decimal tests support another currency without inventing official token addresses; a combined dashboard is P1. Browser wallet integration uses EIP-1193 and viem directly. Parsing is deterministic, explicitly draft-only, and requires no LLM key.

Prices are USD per whole fiat/token unit. The raw weighted LUKAS basket is compatibility methodology, not an economically normalized hedge. Upstream eight-decimal index values are normalized to WAD. Zero reference-token address means index denomination without issuance; TESTCOP/SIMCOP are synthetic. Publisher is separate from executor/owner. A signed mirror trusts its approved attester and preserves original component/token timestamps.

SQLite uses Node's maintained built-in SQLite module, WAL and single-host transactions rather than adding better-sqlite3; Node >=22.13 is required. Chain timestamps/daily budgets are UTC; UI default display is Bogotá. Mainnet exposure/gas limits are supplied by the operator, never invented. Mainnet writes default disabled and read-only reconciliation continues while write authority is absent.

JACK source reuse rights remain unresolved, so the financial runtime is independently implemented and accurately described as JACK-inspired. Protocol issuance/reserve/redemption and SDK release changes belong in the upstream protocol repository. No hosted production deployment, monetary guarantee, real independent user, canonical registration or organizer approval has been fabricated.
